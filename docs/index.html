ENGINEERING SPECIFICATIONS

Core Architecture & Capabilities

Designed from the ground up for minimal resource footprints, complete Linux hardware visibility, and reliable network probing.

⚡

Sub-6ms Hardware Telemetry

Hot-path hardware collection completes in under 6 milliseconds. Process sampling is decoupled to 3.5s intervals, thread counts are read directly from /proc/loadavg, and sysfs paths are cached to eliminate redundant globbing.

🌐

TingPing Prober Engine

Concurrent, non-blocking network probe engine performing ICMP Ping, TCP handshake, and HTTP/HTTPS status tests with dynamic latency badges (<35ms fast, <100ms good, <250ms warn, down).

🔍

Live Diagnostics Suite

Interactive NDJSON streaming tools directly in the browser: live hop-by-hop Traceroute, CIDR Subnet Sweeper (up to /24), DNS Record Resolver (A, AAAA, CNAME, PTR), TCP Port Checker, and Cloudflare Speedtest.

💤

Sleep-On-Idle Zero Waste

When no browser clients are viewing the dashboard, background hardware and network probing loops pause indefinitely with 0% CPU usage and zero outbound network queries.

🔒

SQLite Credential Vault

Zero-dependency authentication vault powered by standard library sqlite3 and memory-hard scrypt password hashing. Session tokens, strict 0600 Linux file permissions, and zero clunky browser popups.

⚙

lscpu Processor Topology

Probes deep CPU silicon details on startup: architecture, silicon stepping, L1/L2/L3 SRAM cache hierarchy, hardware virtualization (AMD-V / VT-x), and vulnerability mitigations with zero polling overhead.

📻

Dual Vintage Aesthetics

Switch seamlessly between Amber Phosphor CRT dark mode (with cathode vignette and glowing filament indicators) and Technical Parchment light mode (with Olivetti typewriter typography).

CREDENTIAL VAULT & AUTHENTICATION

        
Operator Accounts & Terminal Gateway

        
Zero-dependency SQLite credential management with memory-hard scrypt hashing and constant-time verification. Manage operators via web interface or headless terminal commands.

      


      

        
        

          

            1
            
Initial Operator Boot & Web Setup Wizard

          

          

            On first boot with an empty database, WindyDash automatically surfaces the First-Time Setup Wizard to initialize your master administrator credentials. If a legacy DASH_PASSWORD is detected in .env, an admin operator is pre-initialized.
          

          

            Default Operator: "admin" (or initialized via Web Setup Wizard)
          

        


        
        

          

            2
            
List All Registered Operators

          

          

            Query the local SQLite vault directly from your Linux shell to view all authorized telemetry console operators:
          

          

            python3 sysmon.py --listusers
            
          

        


        
        

          

            3
            
Register a New Operator Account

          

          

            Add a new operator with an interactive, masked password prompt. Credentials are automatically salted and hashed using memory-hard scrypt:
          

          

            python3 sysmon.py --adduser <operator>
            
          

        


        
        

          

            4
            
Update an Existing Operator's Passcode

          

          

            Reset or rotate credentials for any operator without restarting the background service:
          

          

            python3 sysmon.py --passwd <operator>
            
          

        

      

    


    
    

      

        
DEPLOYMENT CONTROLLER

        
Automated Systemd Service Setup

        
Use the included service.sh manager script to install, update, or reload WindyDash with a single command.

      


      

        
        

          

            1
            
Install & Register Background Service

          

          

            The manager script validates Python file syntax, auto-detects your virtualenv or Python binary, configures the service unit, and starts the daemon:
          

          

            ./service.sh install
            
          

        


        
        

          

            2
            
Seamless Updates After Modifying Files

          

          

            Whenever you edit code or configuration, execute update. It runs pre-flight syntax checks to guarantee zero downtime before restarting:
          

          

            ./service.sh update
            
          

        


        
        

          

            3
            
Monitor Status & Stream Real-time Journal Logs

          

          

            ./service.sh status     # Check live status & health
            
          

          

            ./service.sh logs       # Stream real-time journal logs
